# PS Türkçe Altyazı (Android TV)

chiaki-ng tabanlı PS5 Remote Play istemcisi. Oyundaki İngilizce altyazıyı ekrandan okur (ML Kit OCR),
cihaz üzerinde Türkçeye çevirir (ML Kit Translate) ve oyunun üstünde gösterir.

Son APK: `releases/latest/download/PSAltyazi.apk`

Lisans: AGPL-3.0 (chiaki-ng ile aynı).
